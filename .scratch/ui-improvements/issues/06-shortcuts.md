# 06: Горячие клавиши для действий интерфейса

## Что сделать

Игрок вызывает все действия согласованного интерфейса клавиатурой. Сочетания доступны в подсказках и учитывают состояние программы.

## Зависит от

ui-improvements/01–04; program-execution/03 — Переключение режимов без перезапуска (включает зависимости от остановки, паузы и шага).

## Критерии приёмки

- [x] Перед реализацией согласован полный список действий и сочетаний для интерфейса, доступного на момент реализации.
- [x] Список охватывает запуск, паузу, продолжение, шаг, остановку, открытие и закрытие настроек, размер текста, сворачивание и раскрытие вывода, копирование и изменение размеров панелей.
- [x] При фокусе на выводе Ctrl+C копирует выделенный текст штатным способом.
- [x] Для перетаскивания границ предусмотрен клавиатурный эквивалент.
- [x] Подсказки кнопок показывают соответствующие сочетания.
- [x] Горячие клавиши соблюдают ту же доступность действий, что и кнопки, и не конфликтуют с вводом кода и стандартными командами редактирования.
- [x] Фокус клавиатуры видим при навигации; команды не вызывают случайных действий игрового поля.

## Проверка в Godot

Запустить игровую сцену. Вызвать согласованные действия без мыши, проверить редактирование текста и доступность команд в редактировании, выполнении и паузе.

## Согласовать перед реализацией

Окончательное оформление и техническое решение. Создание задачи не разрешает изменение игрового кода.
