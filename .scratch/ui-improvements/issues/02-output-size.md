# 02: Изменение высоты и сворачивание вывода

## Что сделать

Игрок меняет высоту панели вывода и сворачивает её, освобождая место для кода, без потери сообщений.

## Зависит от

program-editor/07 — работающая основа панели вывода; завершение проверок будущих режимов не блокирует начало.

## Критерии приёмки

- [ ] Высота панели изменяется перетаскиванием границы с сохранением минимальных размеров областей.
- [ ] Панель можно свернуть и снова раскрыть без потери сообщений.
- [ ] Новый вывод или ошибка раскрывают свёрнутую панель.
- [ ] Сохраняются правила очистки только при новом запуске программы.

## Проверка в Godot

Запустить игровую сцену. Вывести несколько сообщений, изменить высоту, свернуть и раскрыть панель; свернуть ещё раз и получить новое сообщение или ошибку.

## Согласовать перед реализацией

Окончательное оформление и техническое решение. Создание задачи не разрешает изменение игрового кода.
