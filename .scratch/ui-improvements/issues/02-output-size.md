# 02: Изменение высоты и сворачивание вывода

## Что сделать

Игрок меняет высоту панели вывода и сворачивает её, освобождая место для кода, без потери сообщений.

## Зависит от

program-editor/07 — работающая основа панели вывода; завершение проверок будущих режимов не блокирует начало.

## Критерии приёмки

- [x] Высота панели изменяется перетаскиванием границы с сохранением минимальных размеров областей.
- [x] Панель можно свернуть и снова раскрыть без потери сообщений.
- [x] Новый вывод или ошибка раскрывают свёрнутую панель.
- [x] Сохраняются правила очистки только при новом запуске программы.
- [x] Перетаскивание разделителя к нижней границе сворачивает сообщения до заголовка. Нажатие на заголовок восстанавливает высоту до этого перетаскивания.
- [x] Заголовок «Вывод» отображается без стрелки в обоих состояниях, зазор между полем кода и панелью уменьшен.
- [x] Перетаскивание разделителя вверх раскрывает свёрнутый вывод, сохраняя высоту и сообщения.
- [x] Область захвата разделителя увеличена в обоих состояниях, видимый зазор остаётся узким.

## Проверка в Godot

Запустить игровую сцену. Вывести несколько сообщений, изменить высоту панели и потянуть разделитель к нижней границе редактора. Нажать «Вывод» и проверить восстановление высоты и сообщений. Свернуть панель нажатием на заголовок и получить новое сообщение или ошибку. Проверить, что заголовок отображается без стрелки, а зазор над ним уменьшен.

Повторно свернуть вывод и потянуть разделитель вверх, захватив его чуть выше или ниже видимой полоски. После отпускания должны вернуться высота и сообщения.

## Согласовать перед реализацией

Окончательное оформление и техническое решение. Создание задачи не разрешает изменение игрового кода.
