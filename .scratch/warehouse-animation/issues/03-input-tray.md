# 03. Установить приёмный лоток в зоне выдачи

## Что сделать

Коробка доезжает до края входной ленты, падает в лоток и останавливается в точке захвата. Проверить пригодность существующих моделей лотков. Для падения использовать управляемую траекторию с ускорением и фиксированной точкой приземления.

## Блокирующие задачи

Нет.

## Критерии приёмки

- [x] С игровой камеры видно, как коробка покидает край ленты и падает в лоток. Коробка остаётся доступна для захвата с клетки выдачи.
- [x] Ранний `grab()` ждёт окончания подачи. Сброс во время подачи позволяет коробке завершить движение, а сброс после захвата возвращает её в лоток.

## Проверка в Godot

В `SorterGame.tscn` проследить подачу коробки, выполнить `grab()` во время следующей подачи и проверить сброс с грузом.

## Comments

- По README ассетов использован существующий `tray_orange.glb`. Точка захвата стоит над полозьями лотка, слева от клетки выдачи. Прогон в Godot 4.7.2 с Forward+ подтвердил видимость падения, продолжение первой подачи после сброса, ожидание `grab()` при следующей подаче и возврат захваченной коробки в лоток. Целевой тест `--input-tray` прошёл 6 проверок при фиксированных 20 кадрах/с. Полный набор прошёл 762 проверки при фиксированных 120 кадрах/с.
