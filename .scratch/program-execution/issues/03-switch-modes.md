# 03: Переключение режимов без перезапуска

## Что сделать

Игрок ставит автоматическое выполнение на паузу, делает отдельные шаги полым треугольником и продолжает автоматически заполненным треугольником. Обе кнопки продолжают один запуск с той же следующей невыполненной инструкции.

## Зависит от

program-execution/02 — Выполнение по кнопке «Шаг»

## Критерии приёмки

- [x] После появления program-editor/07 переключение режимов сохраняет сообщения: продолжается тот же запуск.
- [x] Переход из автоматического выполнения к отдельным шагам происходит через паузу: текущая инструкция и анимация завершаются, затем игрок нажимает «Шаг». Из ожидания после шага игрок может продолжить автоматически.
- [x] Продолжение в любом режиме сохраняет состояние текущего запуска и выполняет следующую невыполненную инструкцию без повторения завершённой строки.
- [x] Переключение не пропускает и не повторяет инструкции.
- [x] Остановка с последующим запуском по-прежнему начинает программу с первой строки.

## Проверка в Godot

После появления окна вывода получить сообщение, переключить режим в обе стороны и проверить, что оно не очищается.

Запустить игровую сцену с редактором. Запросить паузу посреди движения, дождаться завершения инструкции, сделать отдельный шаг, затем продолжить автоматически; проверить отсутствие пропусков и повторений. По мере появления переменных и функций проверить сохранение их состояния.

## Согласовать перед реализацией

Вид подсветки между шагами. Пауза после завершения текущей команды и продолжение со следующей невыполненной инструкции уже согласованы. Архитектура и техническая реализация требуют отдельного согласования.
