# 02: Выполнение по кнопке «Шаг»

## Что сделать

Вторая кнопка с полым треугольником в заголовке редактора выполняет одну инструкцию и переводит программу в паузу. Из редактирования начинается новый запуск с первой строки; из паузы продолжается текущий запуск со следующей невыполненной инструкции.

## Зависит от

program-execution/01 — Автоматическое выполнение с подсветкой строки; sorter-bot-concept/03 — Остановка и повторный запуск

execution-pause/01 — Пауза и продолжение автоматического выполнения.

## Критерии приёмки

- [x] После появления program-editor/07 «Шаг» из паузы сохраняет сообщения текущего запуска; «Шаг» из редактирования начинает новый запуск и очищает прежний вывод.
- [x] Одно нажатие «Шаг» выполняет одну инструкцию, затем программа ждёт следующего нажатия.
- [x] Выполняемая строка подсвечивается; действие робота и анимация завершаются до следующего шага.
- [x] Полная остановка во время шага дожидается завершения его инструкции и анимации, затем завершает запуск. В ожидании шага остановка завершает запуск без дополнительной инструкции. Первая правка применяется сразу и запрашивает такую же полную остановку.
- [x] Просмотр, копирование и перемещение курсора не останавливают выполнение.
- [x] Ожидание следующего шага отличается от остановки и завершения программы.
- [x] В редактировании полый треугольник начинает выполнение с первой строки и выполняет одну инструкцию; в паузе выполняет одну следующую невыполненную инструкцию.
- [x] После шага программа снова находится в паузе; после последней инструкции завершается и возвращает кнопки в состояние редактирования.
- [x] Во время выполнения первая кнопка показывает паузу, вторая — недоступный полый треугольник, третья — остановку. В паузе первая и вторая кнопки доступны для автоматического и пошагового продолжения, третья — для остановки.
- [x] При редактировании первая кнопка запускает автоматически, вторая выполняет первый шаг, третья недоступна. Места кнопок не меняются.

## Проверка в Godot

После появления окна вывода выполнить несколько шагов с выводом и проверить сохранение предыдущих сообщений этого запуска.

Запустить игровую сцену с редактором. Выполнить несколько команд отдельными нажатиями и проверить ожидание между ними. Во время ожидания изменить код: проверить остановку и применение первого символа; новый запуск начинается с первой строки.

## Согласовать перед реализацией

Окончательное оформление и подсветка в паузе. Шаги условий уточняются в задачах 10 и 11 основного плана. Архитектура и техническая реализация требуют отдельного согласования.
