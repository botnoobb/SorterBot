# 01: Автоматическое выполнение с подсветкой строки

## Что сделать

Программа автоматически переходит к следующему шагу после завершения текущего.

## Зависит от

sorter-bot-concept/01 — Минимальный интерпретатор: первая программа

## Критерии приёмки

- [x] Программа автоматически переходит к следующему шагу после завершения текущего.
- [x] В редакторе подсвечивается выполняемая строка независимо от наличия подсветки синтаксиса.
- [x] Длительность шага задаёт темп выполнения; анимация действия робота подстраивается под неё.
- [x] Действие робота и его анимация завершаются до начала следующего шага.

## Проверка в Godot

Запустить игровую сцену с редактором. Запустить программу из нескольких команд, наблюдать подсветку строк и убедиться, что следующая команда начинается после завершения действия и анимации предыдущей.

## Согласовать перед реализацией

Численная длительность шагов и вид подсветки между шагами. Архитектура и техническая реализация требуют отдельного согласования.
