# 02: Диагностика ошибок программы игрока

## Что сделать

Игрок получает диагностику ошибки своего кода в привычном формате Python с английскими сообщениями и может перейти к проблемной строке.

## Зависит от

program-errors/01 — Ошибки кода игрока в формате Python.

## Критерии приёмки

- [x] Ошибка языка автоматически раскрывает общее окно вывода program-editor/07 и визуально отличается от обычного вывода игрока.
- [x] Редактирование сохраняет сообщения об ошибках; очистка происходит при новом запуске, а не при нажатии «Шаг» или переключении режима.
- [x] Ошибки языка корректно завершают выполнение в автоматическом и пошаговом режимах; дальнейшие шаги ошибочного запуска не выполняются.
- [x] Сообщения об ошибках отображаются в общем окне вывода под редактором.
- [x] Нажатие на сообщение переводит к проблемной строке и выделяет её.
- [x] Новый запуск очищает прежнюю ошибку.
- [x] Некорректная программа показывает тип ошибки, контекст исходного кода и английское диагностическое сообщение в привычном формате Python без дополнительных учебных подсказок.
- [x] Диагностика относится к коду игрока; внутренние файлы GDScript не показываются. Точное совпадение с конкретной версией Python не требуется.

## Согласовать перед реализацией

Состав ошибок минимального языка и поведение при ошибке выполнения.

Архитектура и технический способ реализации требуют отдельного согласования. Создание задачи и метка ready-for-agent не разрешают изменение игрового кода.

## Проверка в Godot

Вызвать ошибку при скрытой панели, перейти к строке через сообщение, исправить код и проверить сохранение сообщения до нового запуска.

Проверить ошибку языка в обоих режимах: сообщение доступно, выполнение прекращено.

Ввести некорректную программу, запустить её, перейти к строке через сообщение; исправить код и проверить очистку прежней ошибки при запуске.

Запустить сцену, подготовленную для этой возможности, и воспроизвести описанное поведение. Проверить каждый критерий приёмки. Конкретные программы, действия и технические проверки уточнить при согласовании реализации.
