# 15: Прогресс первого заказа

## Что сделать

Игрок видит цель заказа и накопленный результат подходящих доставок.

## Зависит от

07 — Следующая коробка после доставки; 10 — Выбор зоны через условие

## Критерии приёмки

- [x] Прогресс увеличивают только правильно доставленные коробки, соответствующие условию заказа.
- [x] Правильная доставка неподходящего вида не увеличивает прогресс этого заказа.
- [x] Редактирование кода и восстановление текущего груза не сбрасывают прогресс по предыдущим грузам.

## Согласовать перед реализацией

Согласован заказ на три оранжевые коробки. Цель и счётчик видны в карточке задания над полем. Поле передаёт цвет доставленной коробки в сигнале успешной доставки, а игровая сцена ведёт счётчик и показывает выполнение заказа при достижении цели.

## Проверка в Godot

Запустить `SorterGame.tscn`. Карточка задания показывает «Заказ: оранжевые коробки — 0 из 3».

1. В примере из справки «Условия» добавить `move("down")` перед `put()` в ветке для оранжевой коробки и запустить программу. Доставка в синюю зону оставляет «0 из 3».
2. Запустить `move("up")` и `put()` отдельными строками одной программы. Счётчик показывает «1 из 3».
3. Нажать «Начать текущий груз заново», чтобы вернуть робота на старт. Сократить пример из справки до `grab()` включительно и запустить его. После захвата нажать «Начать текущий груз заново» ещё раз. Счётчик остаётся на «1 из 3».
4. Повторять исходный пример из справки, возвращая робота на старт после каждой доставки. Доставка синей коробки сохраняет показание счётчика. После третьей оранжевой коробки появится «Заказ выполнен: 3 из 3 оранжевых». Если синие коробки не успели поступить до выполнения заказа, перезапустить сцену для проверки синей доставки.
