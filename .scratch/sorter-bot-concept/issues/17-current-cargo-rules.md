# 17: Новые правила для уже появившейся коробки

## Что сделать

Игрок принимает заказ при наличии груза и доставляет его по новым требованиям.

## Зависит от

16 — Предложение и принятие следующего заказа

## Критерии приёмки

- [x] Наличие текущей коробки не препятствует принятию заказа.
- [x] Текущая коробка сохраняется без изменения свойств.
- [x] Правильность её доставки определяется новыми требованиями, даже если назначение изменилось.

## Проверка в Godot

1. Запустить `SorterGame.tscn`, выполнить первый заказ и остановить программу после третьей оранжевой коробки. Следующая коробка синяя. Вернуть робота на старт кнопкой «Начать текущий груз заново».
2. В примере из раскрытой карточки задания удалить последнюю строку `put()` и запустить его. Робот должен удерживать синюю коробку на верхней клетке доставки.
3. Нажать «Принять заказ». Убедиться, что коробка осталась в захватах и сохранила цвет. Выполнить `move("down")` и `put()` отдельными строками одной программы. Нижняя зона отклонит доставку, коробка останется у робота, счётчик покажет «0 из 3».
4. Выполнить `move("up")` и `put()` отдельными строками одной программы. Верхняя зона примет коробку, счётчик покажет «1 из 3».
