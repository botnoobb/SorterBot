# 17: Новые правила для уже появившейся коробки

## Что сделать

Игрок принимает заказ при наличии груза и доставляет его по новым требованиям.

## Зависит от

16 — Предложение и принятие следующего заказа

## Критерии приёмки

- [ ] Наличие текущей коробки не препятствует принятию заказа.
- [ ] Текущая коробка сохраняется без изменения свойств.
- [ ] Правильность её доставки определяется новыми требованиями, даже если назначение изменилось.

## Согласовать перед реализацией

Проверяемый пример изменения назначения текущей коробки.

Архитектура и технический способ реализации требуют отдельного согласования. Создание задачи и метка ready-for-agent не разрешают изменение игрового кода.

## Проверка в Godot

Запустить сцену, подготовленную для этой возможности, и воспроизвести описанное поведение. Проверить каждый критерий приёмки. Конкретные программы, действия и технические проверки уточнить при согласовании реализации.
