# 23: Скоростное испытание

## Что сделать

После покупки максимальной скорости игрок может пройти необязательное испытание производительности.

## Зависит от

- [ ] При согласовании измерения производительности учитывается общий темп выполнения программы и анимаций.
- [ ] Покупка максимальной скорости открывает предложение испытания.
- [ ] Игрок видит результат по согласованным правилам измерения.
- [ ] Дальнейшее повышение производительности достигается изменением программы.
