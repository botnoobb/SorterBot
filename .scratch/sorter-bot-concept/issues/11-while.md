# 11: Цикл while для повторной обработки

## Что сделать

Игрок организует повторные доставки циклом while.

## Зависит от

program-execution/02 — Выполнение по кнопке «Шаг»

03 — Остановка и повторный запуск; 07 — Следующая коробка после доставки

## Критерии приёмки

- [ ] Первая и каждая повторная проверка условия while выполняются отдельным шагом от команд тела цикла.
- [ ] Правило шагов действует в обоих режимах; бесконечный цикл, в том числе без действий робота, доступен для остановки.
- [ ] Если подсветка редактора уже реализована, она поддерживает добавляемые конструкции. Иначе эти конструкции входят в последующую проверку program-editor/04.
- [ ] Программа игрока выполняет повторную обработку через while.
- [ ] Игрок может остановить бесконечный цикл, включая цикл без действий робота.
- [ ] Задание объясняет практическую пользу цикла.

## Согласовать перед реализацией

Семантика цикла и механизм прерывания, обеспечивающий доступность управления.

Архитектура и технический способ реализации требуют отдельного согласования. Создание задачи и метка ready-for-agent не разрешают изменение игрового кода.

## Проверка в Godot

Пройти цикл по шагам, включая повторную проверку и выход, затем автоматически; проверить остановку бесконечного цикла без действий робота.

Запустить сцену, подготовленную для этой возможности, и воспроизвести описанное поведение. Проверить каждый критерий приёмки. Конкретные программы, действия и технические проверки уточнить при согласовании реализации.
