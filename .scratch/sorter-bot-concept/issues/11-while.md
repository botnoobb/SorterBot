# 11: Цикл while для повторной обработки

## Что сделать

Игрок организует повторные доставки циклом while.

## Критерии приёмки

- [x] Первая и каждая повторная проверка условия while выполняются отдельным шагом от команд тела цикла.
- [x] Правило шагов действует в обоих режимах; бесконечный цикл, в том числе без действий робота, доступен для остановки.
- [x] Если подсветка редактора уже реализована, она поддерживает добавляемые конструкции. Иначе эти конструкции входят в последующую проверку program-editor/04.
- [x] Программа игрока выполняет повторную обработку через while.
- [x] Игрок может остановить бесконечный цикл, включая цикл без действий робота.
- [x] Задание объясняет практическую пользу цикла.

## Проверка в Godot

Запустить `SorterGame.tscn` и выполнить по шагам, затем автоматически:

```python
state = "repeat"
while state == "repeat":
    state = "done"
print(state)
```

Строка `while` подсвечивается дважды, а команда тела выполняется один раз.
В выводе появляется `done`. Затем запустить пример из справки «Цикл while» и
нажать «Стоп» после двух доставок. Отдельно запустить `while True:` с
командой `pass` на следующей строке с отступом и проверить кнопку «Стоп».
