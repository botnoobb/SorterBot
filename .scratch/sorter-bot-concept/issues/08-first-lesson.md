## Что сделать

Новичок проходит вводное задание с объяснением, запуском команд и наблюдением доставки.

## Критерии приёмки

- [x] Вводное задание знакомит с подсветкой выполняемой строки, кнопкой «Шаг» и переключением режимов без перезапуска.
- [x] Игрок знакомится с вводом, запуском, остановкой и поиском ошибки в редакторе.
- [x] Описание первой команды доступно в справке рядом с кодом.
- [x] Задание можно пройти без предварительных знаний программирования.
- [x] Игрок читает краткое объяснение, запускает команды и наблюдает результат.
- [x] Объяснение можно открыть повторно.

Содержание первого задания, текст объяснения и способ его показа.

Архитектура и технический способ реализации требуют отдельного согласования. Создание задачи и метка ready-for-agent не разрешают изменение игрового кода.

Пройти вводное задание: выполнить команды автоматически и по шагам, переключить режим с текущего места.
