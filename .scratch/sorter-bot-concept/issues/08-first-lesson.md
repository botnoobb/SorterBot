# 08: Первое знакомство с командами

## Что сделать

Новичок проходит вводное задание с объяснением, запуском команд и наблюдением доставки.

## Зависит от

program-execution/03 — Переключение режимов без перезапуска

program-editor/06 — Справка рядом с кодом.

02 — Ошибки языка с понятным объяснением; 06 — Начать текущий груз заново; 07 — Следующая коробка после доставки

## Критерии приёмки

- [ ] Вводное задание знакомит с подсветкой выполняемой строки, кнопкой «Шаг» и переключением режимов без перезапуска.
- [ ] Игрок знакомится с вводом, запуском, остановкой и поиском ошибки в редакторе.
- [ ] Описание первой команды доступно в справке рядом с кодом.
- [ ] Задание можно пройти без предварительных знаний программирования.
- [ ] Игрок читает краткое объяснение, запускает команды и наблюдает результат.
- [ ] Объяснение можно открыть повторно.

## Согласовать перед реализацией

Содержание первого задания, текст объяснения и способ его показа.

Архитектура и технический способ реализации требуют отдельного согласования. Создание задачи и метка ready-for-agent не разрешают изменение игрового кода.

## Проверка в Godot

Пройти вводное задание: выполнить команды автоматически и по шагам, переключить режим с текущего места.

Пройти вводное задание, запустить и остановить программу, найти строку ошибки и открыть справку.

Запустить сцену, подготовленную для этой возможности, и воспроизвести описанное поведение. Проверить каждый критерий приёмки. Конкретные программы, действия и технические проверки уточнить при согласовании реализации.
