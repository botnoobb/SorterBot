# 14: Возвращаемое значение функции

## Что сделать

Игрок выносит выбор назначения в функцию и использует её результат при доставке.

## Зависит от

10 — Выбор зоны через условие; 13 — Параметры функций

## Критерии приёмки

- [ ] Возвращаемые значения функций корректно используются в обоих режимах выполнения.
- [ ] Если подсветка редактора уже реализована, она поддерживает добавляемые конструкции. Иначе эти конструкции входят в последующую проверку program-editor/04.
- [ ] Функция возвращает значение вызывающей программе.
- [ ] Результат выбора назначения используется при доставке.
- [ ] Объяснение связывает возвращаемое значение с практической задачей.

## Согласовать перед реализацией

Границы шагов при вызове и возврате собственных функций остаются открытым вопросом; не определять их без согласования.

Синтаксис возврата и поведение функции без явного возвращаемого значения.

Архитектура и технический способ реализации требуют отдельного согласования. Создание задачи и метка ready-for-agent не разрешают изменение игрового кода.

## Проверка в Godot

В обоих режимах получить назначение из функции и использовать его при доставке.

Запустить сцену, подготовленную для этой возможности, и воспроизвести описанное поведение. Проверить каждый критерий приёмки. Конкретные программы, действия и технические проверки уточнить при согласовании реализации.
