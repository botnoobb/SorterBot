# 14: Возвращаемое значение функции

## Что сделать

Игрок выносит выбор назначения в функцию и использует её результат при доставке.

## Зависит от

10 — Выбор зоны через условие; 13 — Параметры функций

## Критерии приёмки

- [x] Возвращаемые значения функций корректно используются в обоих режимах выполнения.
- [x] Если подсветка редактора уже реализована, она поддерживает добавляемые конструкции. Иначе эти конструкции входят в последующую проверку program-editor/04.
- [x] Функция возвращает значение вызывающей программе.
- [x] Результат выбора назначения используется при доставке.
- [x] Объяснение связывает возвращаемое значение с практической задачей.

## Согласовать перед реализацией

Границы шагов при вызове и возврате собственных функций остаются открытым вопросом; не определять их без согласования.

Синтаксис возврата и поведение функции без явного возвращаемого значения.

Архитектура и технический способ реализации требуют отдельного согласования. Создание задачи и метка ready-for-agent не разрешают изменение игрового кода.

## Проверка в Godot

Запустить сцену `scenes/SorterGame.tscn` клавишей F6. Открыть «Справка → Функции»
и вставить код из раздела «Возвращаемое значение». Запустить программу и
проверить доставку. Нажать «Начать текущий груз заново» и выполнить пример
кнопкой «Шаг» со следующей коробкой. Строка вызова, инструкции тела и явный
`return` подсвечиваются последовательно. После возврата выполняется следующая
инструкция вызывающей программы.
