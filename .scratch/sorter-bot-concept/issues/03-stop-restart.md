# 03: Остановка и повторный запуск

## Что сделать

В заголовке редактора три постоянных места: запуск/пауза/продолжение, шаг, остановка. Игрок запускает программу первой кнопкой с заполненным треугольником и полностью останавливает третьей кнопкой с квадратом. После остановки или завершения возвращается состояние редактирования.

## Зависит от

01 — Минимальный интерпретатор: первая программа

program-execution/01 — Автоматическое выполнение с подсветкой строки (завершена).

## Критерии приёмки

- [x] После появления program-editor/07 остановка, завершение и редактирование сохраняют сообщения, включая остановку первой правкой.
- [x] Новый запуск очищает прежние сообщения; при отсутствии новых панель скрыта, первый вывод или ошибка раскрывает её.
- [x] Ожидание кнопки «Шаг» отличается от остановки и завершения программы.
- [x] В пошаговом режиме, включая ожидание нажатия, остановка и редактирование сохраняют согласованное поведение: первая правка останавливает выполнение и сразу применяется.
- [x] Первая правка сразу применяется без потери введённого символа и запрашивает полную остановку: уже начатая инструкция и анимация завершаются, следующая инструкция старого запуска не начинается. В паузе правка завершает запуск без дополнительного шага.
- [x] Вставка, удаление, отмена и возврат изменений также останавливают выполнение, если меняют текст.
- [x] Выделение, копирование, перемещение курсора и просмотр кода не останавливают выполнение.
- [x] Интерфейс показывает состояния «Выполняется», «Остановлена», «Завершена» и доступность кнопок запуска и остановки.
- [x] Полная остановка, как и пауза, дожидается полного выполнения текущей инструкции и её анимации. Следующая инструкция не начинается; текущий запуск завершается без возможности продолжения.
- [x] Остановка из паузы завершает запуск без выполнения дополнительной инструкции.
- [x] Остановка и обычное завершение сохраняют расположение объектов, достигнутое после завершения текущей инструкции.
- [x] Повторный запуск выполняет программу с первой строки.
- [x] Третья кнопка всегда показывает квадрат: недоступна при редактировании, доступна во время выполнения и паузы. Проверка паузы выполняется после execution-pause/01.
- [x] Три места кнопок постоянны, панель не сдвигается при смене состояния; подсказки объясняют действия.
- [x] Первая кнопка запускает программу; после подключения execution-pause/01 она меняется на паузу при выполнении и на продолжение в паузе. До подключения соответствующие действия недоступны.
- [x] После остановки следующий автоматический или пошаговый запуск начинается с первой строки; проверка пошагового запуска выполняется после program-execution/02.
- [x] После подключения execution-pause/01 нажатие «Пауза» не прерывает текущую строку: её команда и анимация завершаются полностью, затем программа ждёт перед следующей невыполненной инструкцией. Если текущая команда последняя, программа завершается.
- [x] Продолжение после паузы, автоматическое или пошаговое, начинается со следующей невыполненной инструкции без повторения завершённой строки и без очистки вывода. Пауза сохраняет текущий запуск; полная остановка завершает его и требует нового запуска с первой строки.

## Согласовать перед реализацией

Завершение текущей инструкции и её анимации перед паузой и полной остановкой уже согласовано; этот вопрос закрыт. Остановка из паузы уже согласована: третья кнопка с квадратом. Начало нового запуска с первой строки уже согласовано.

Архитектура и технический способ реализации требуют отдельного согласования. Создание задачи и метка ready-for-agent не разрешают изменение игрового кода.

## Проверка в Godot

Нажать полную остановку посреди движения: текущая инструкция и анимация завершаются, следующая инструкция не начинается. Новый запуск идёт с первой строки. Проверить то же при первой правке во время движения: текст меняется сразу, начатое действие завершается. После появления окна вывода проверить сохранение сообщений при остановке, завершении и первой правке и очистку при новом запуске.

Проверить остановку и правку в обоих режимах, в том числе при ожидании шага; после остановки новый запуск идёт с первой строки.

После появления execution-pause/01 нажать паузу во время команды движения: команда и анимация завершаются, следующая команда не начинается. Продолжить автоматически, а после появления program-execution/02 — отдельно проверить пошаговое продолжение: завершённая строка не повторяется, вывод сохраняется. Для сравнения полностью остановить программу из паузы и проверить запуск с первой строки. Запрос паузы во время последней команды должен приводить к обычному завершению программы.

Во время выполнения ввести символ: проверить остановку, применение символа и сохранение расположения объектов. Отдельно проверить просмотр и копирование без остановки, затем повторный запуск с первой строки.

Запустить сцену, подготовленную для этой возможности, и воспроизвести описанное поведение. Проверить каждый критерий приёмки. Конкретные программы, действия и технические проверки уточнить при согласовании реализации.
