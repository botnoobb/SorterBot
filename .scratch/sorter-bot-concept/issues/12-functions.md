# 12: Собственная функция без параметров

## Что сделать

Игрок выносит повторяющиеся действия в собственную функцию и вызывает её.

## Зависит от

program-execution/02 — Выполнение по кнопке «Шаг»

11 — Цикл while для повторной обработки

## Критерии приёмки

- [ ] Собственные функции работают в автоматическом и пошаговом режимах с подсветкой выполняемой строки.
- [ ] Если подсветка редактора уже реализована, она поддерживает добавляемые конструкции. Иначе эти конструкции входят в последующую проверку program-editor/04.
- [ ] Программа позволяет определить функцию без параметров и вызвать её.
- [ ] Вызов выполняет вынесенные действия робота.
- [ ] Короткое объяснение сопровождает практическое задание.

## Согласовать перед реализацией

Границы шагов при вызове и возврате собственных функций остаются открытым вопросом; не определять их без согласования.
