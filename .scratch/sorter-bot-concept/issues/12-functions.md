# 12: Собственная функция без параметров

## Что сделать

Игрок выносит повторяющиеся действия в собственную функцию и вызывает её.

## Зависит от

program-execution/02 — Выполнение по кнопке «Шаг»

11 — Цикл while для повторной обработки

## Критерии приёмки

- [x] Собственные функции работают в автоматическом и пошаговом режимах с подсветкой выполняемой строки.
- [x] Если подсветка редактора уже реализована, она поддерживает добавляемые конструкции. Иначе эти конструкции входят в последующую проверку program-editor/04.
- [x] Программа позволяет определить функцию без параметров и вызвать её.
- [x] Вызов выполняет вынесенные действия робота.
- [x] Короткое объяснение сопровождает практическое задание.

## Согласовать перед реализацией

Границы шагов при вызове и возврате собственных функций остаются открытым вопросом; не определять их без согласования.

Синтаксис функций, правила вызова и области видимости.

Архитектура и технический способ реализации требуют отдельного согласования. Создание задачи и метка ready-for-agent не разрешают изменение игрового кода.

## Проверка в Godot

Запустить сцену `scenes/SorterGame.tscn` клавишей F6 и открыть «Справка → Функции».
Вставить пример из справки и запустить. Робот должен доставить две коробки в зоны их цветов.
Перезапустить сцену и повторить пример кнопкой «Шаг». Проверить, что вызов
`deliver()` подсвечивается отдельно, затем подсвечиваются инструкции тела,
а после его завершения выполняется следующая инструкция после вызова.
