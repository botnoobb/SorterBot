# 01: Минимальный интерпретатор: первая программа

## Что сделать

Игрок вводит программу, запускает её и видит выполнение одной согласованной команды робота.

## Зависит от

Нет — можно начинать после согласования реализации.

## Критерии приёмки

- [x] Игрок вводит многострочный код в боковом редакторе с номерами строк, нажимает «Запустить» и наблюдает действие робота на игровом поле рядом.
- [x] Размещение редактора можно изменить без переписывания редактирования, запуска и сообщений. Конкретное устройство кода согласуется при реализации.
- [x] Для MVP реализуется боковой редактор. Выбор стороны описан в program-editor/01; оконный режим отложен.
- [x] Референсы являются примерным ориентиром, а не финальным дизайном. Вкладки нескольких файлов, пауза, консоль и команды на изображениях не считаются автоматически согласованными возможностями.
- [x] Введённая программа выполняется встроенным интерпретатором.
- [x] Результат команды виден в игровой сцене.

## Согласовать перед реализацией

Минимальный синтаксис, семантика и команда робота; техническое устройство редактора с возможностью будущего оконного размещения. Ввод программы через боковой редактор уже согласован.

Архитектура и технический способ реализации требуют отдельного согласования. Создание задачи и метка ready-for-agent не разрешают изменение игрового кода.

## Проверка в Godot

Запустить сцену с редактором, ввести программу и нажать «Запустить»: проверить номера строк и наблюдаемое действие робота рядом.

Запустить сцену, подготовленную для этой возможности, и воспроизвести описанное поведение. Проверить каждый критерий приёмки. Конкретные программы, действия и технические проверки уточнить при согласовании реализации.
