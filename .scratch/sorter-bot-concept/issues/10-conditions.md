# 10: Выбор зоны через условие

## Что сделать

Игрок выбирает назначение коробки по её свойству.

## Зависит от

program-execution/02 — Выполнение по кнопке «Шаг»

09 — Переменные и чтение свойства груза

## Критерии приёмки

- [x] Проверка условия if занимает отдельный шаг; команда выбранной ветви выполняется следующим отдельным шагом.
- [x] Последовательность проверки и выбранных команд наблюдаема в обоих режимах с подсветкой выполняемой строки.
- [x] Если подсветка редактора уже реализована, она поддерживает добавляемые конструкции. Иначе эти конструкции входят в последующую проверку program-editor/04.
- [x] Условие позволяет программе выбирать между назначениями.
- [x] Небольшое задание объясняет применение условий.
- [x] Принимается любой алгоритм, выполняющий требования зон.

## Согласовать перед реализацией

Синтаксис и семантика условий, свойства и требования учебного задания.

Архитектура и технический способ реализации требуют отдельного согласования. Создание задачи и метка ready-for-agent не разрешают изменение игрового кода.

## Проверка в Godot

Запустить `SorterGame.tscn` и перенести в редактор пример из справки «Условия».
Выполнить его кнопкой «Шаг» на коробке `orange`. Строка `if` проверяется
отдельно, следующая команда выполняет `put()` в зоне `orange`.

Нажать «Начать текущий груз заново» и повторить для коробки `blue`.
После проверки `if` робот должен выполнить `move("down")` и затем `put()`
в зоне `blue`. Проверить обе ветви автоматическим запуском.

Попробовать положить коробку в зону другого цвета. Игра должна сообщить,
какая зона нужна, и сохранить коробку у робота.
