# 19: Учебный заказ на изменение прежней программы

## Что сделать

Игрок развивает собственную программу при изменении требований, сохраняя обработку знакомых грузов.

## Зависит от

14 — Возвращаемое значение функции; 18 — Генерация грузов с покрытием случаев

## Критерии приёмки

- [ ] Учебный заказ требует изменить прежнее решение, сохранив необходимое поведение.
- [ ] Ранее написанный код остаётся основой для работы игрока.
- [ ] Функции помогают организовать решение, но их использование не обязательно для зачёта.
- [ ] Любое решение, выполняющее действующие требования, принимается.

## Согласовать перед реализацией

Содержание заказа и конкретное изменение правил; сохранение между сессиями отдельно не определено.

Архитектура и технический способ реализации требуют отдельного согласования. Создание задачи и метка ready-for-agent не разрешают изменение игрового кода.

## Проверка в Godot

Запустить сцену, подготовленную для этой возможности, и воспроизвести описанное поведение. Проверить каждый критерий приёмки. Конкретные программы, действия и технические проверки уточнить при согласовании реализации.
