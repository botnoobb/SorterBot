# 03. Собрать плиточное поле

## Что сделать

Собрать поле 5×5 из `floor_tile.glb`. Ориентир по оформлению — наклонная камера сверху, тёплые плитки и тёмная рама по краям поля.

## Блокирующие задачи

Нет.

## Критерии приёмки

- [ ] С игровой камеры видны все 25 клеток и их границы.
- [ ] Робот перемещается по клеткам. У левого края напротив верхней клетки и у правого края напротив третьего и четвёртого рядов есть место для конвейеров.

## Проверка в Godot

Запустить игровую сцену, осмотреть поле и провести робота вдоль края.
