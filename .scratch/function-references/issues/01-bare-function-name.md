# 01: Обращение к имени функции без вызова

## Что сделать

Игрок может написать известное имя функции отдельной строкой без скобок. Такая инструкция допустима, но не вызывает функцию и ничего не выводит, как в обычном Python-скрипте.

## Зависит от

program-errors/01 — Ошибки кода игрока в формате Python.

## Критерии приёмки

- [ ] Отдельные строки move и print принимаются без SyntaxError.
- [ ] Обращение к известному имени без скобок не двигает робота, не вызывает функцию и не выводит сообщение, включая пустую строку в панели.
- [ ] Следующие инструкции программы выполняются как обычно.
- [ ] Вызовы функций со скобками сохраняют прежнее поведение.
- [ ] Неизвестное имя без скобок вызывает NameError при выполнении соответствующей строки, а не на этапе синтаксического разбора; предшествующие инструкции успевают выполниться.
- [ ] Лишние токены после имени не игнорируются: некорректный синтаксис остаётся ошибкой.
- [ ] Обращение к имени учитывается как отдельная инструкция с подсветкой строки. При появлении пошагового режима оно занимает один шаг.

## Границы задачи

Задача охватывает уже известные интерпретатору функции. Присваивание функций переменным и передача функций как аргументов не входят в объём работы. Поддержка обращения к имени сама по себе не добавляет новые функции языка.

## Проверка в Godot

Запустить игровую сцену с редактором. Ввести отдельными строками move, print и затем обычный корректный вызов: первые две инструкции подсвечиваются, но не вызывают действий и не создают вывода; вызов выполняется. Проверить программу только с известными именами: она завершается без ошибки и сообщений.

Отдельно выполнить корректную команду, затем неизвестное имя и ещё одну команду: первая выполняется, неизвестное имя даёт NameError, последняя не выполняется. Проверить некорректную строку с лишними токенами и сохранение поведения обычных вызовов. После появления пошагового режима проверить одно нажатие на каждое обращение к имени.

## Согласовать перед реализацией

Конкретное техническое решение. Поведение и отдельный шаг для обращения к имени согласованы; создание задачи не является разрешением на изменение игрового кода.
