# 01: Пауза и продолжение автоматического выполнения

## Что сделать

Игрок нажимает первую кнопку с двумя полосками во время выполнения. Робот заканчивает текущую команду, после чего программа ждёт перед следующей невыполненной инструкцией. Левая кнопка с заполненным треугольником продолжает автоматическое выполнение с этого места.

## Зависит от

sorter-bot-concept/03 — Остановка и повторный запуск.

## Критерии приёмки

- [x] Во время выполнения первая кнопка показывает две полоски паузы, вторая — недоступный полый треугольник шага, третья — доступный квадрат остановки.
- [x] Запрос паузы позволяет текущей команде и анимации завершиться; следующая инструкция не начинается автоматически.
- [x] В паузе первая кнопка показывает заполненный треугольник автоматического продолжения, вторая — полый треугольник пошагового продолжения, третья — доступный квадрат полной остановки. Действие полого треугольника подключается в program-execution/02; до этого кнопка недоступна.
- [x] Автоматическое продолжение выполняет следующую невыполненную инструкцию без повторения завершённой команды, пропусков и нового запуска.
- [x] Пауза и продолжение сохраняют состояние программы, положение объектов и сообщения текущего запуска.
- [x] Если текущая команда последняя, программа завершается, а не остаётся в паузе без следующей инструкции.
- [x] И пауза, и полная остановка дожидаются завершения текущей инструкции и анимации. Пауза сохраняет запуск для продолжения со следующей инструкции; полная остановка завершает запуск, следующий запуск начинается с первой строки. Остановка из паузы не выполняет дополнительную инструкцию.

## Проверка в Godot

Запустить игровую сцену с программой из нескольких перемещений и сообщений. Нажать паузу во время движения: робот завершает его и не начинает следующую команду. Проверить смену значков. Нажать заполненный треугольник: выполнение продолжается со следующей инструкции, сообщения сохраняются. Повторить запрос паузы на последней команде и проверить завершение. Отдельно остановить программу третьей кнопкой из паузы и проверить новый запуск с первой строки.

## Согласовать перед реализацией

Окончательное оформление и подсветку строки в паузе, техническую реализацию. Полная остановка из паузы вызывается третьей кнопкой с квадратом.
