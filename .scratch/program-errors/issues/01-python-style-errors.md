# 01: Ошибки кода игрока в формате Python

## Что сделать

Игрок видит ошибки своего кода в привычном формате Python с английскими диагностическими сообщениями вместо прямых учебных подсказок. Задача изменяет существующие сообщения и их отображение в окне вывода; точное совпадение с конкретной версией Python не требуется.

sorter-bot-concept/01 — Минимальный интерпретатор: первая программа.

## Критерии приёмки

- [x] Существующие учебные подсказки лексера и парсера заменены английской диагностикой в привычном формате Python.
- [x] Синтаксическая ошибка показывает место в исходном коде игрока, строку кода, указатель места ошибки и заключительное сообщение соответствующего типа, например SyntaxError: invalid syntax.
- [x] Для ошибок выполнения поддерживается представление с заголовком Traceback (most recent call last):, местом возникновения в программе игрока и заключительной строкой с типом и английским сообщением.
- [x] Тип ошибки соответствует причине; все ошибки не сводятся к SyntaxError. Конкретное соответствие типов поддерживаемым случаям согласуется перед реализацией.
- [x] Диагностика не содержит дополнительных учебных объяснений, готовых исправлений и перечислений допустимых команд.
- [x] Показывается исходный код игрока, а не внутренние файлы GDScript.
- [ ] Сохраняются правила окна вывода: ошибка раскрывает панель; только новый запуск очищает сообщения; остановка, завершение, редактирование, шаги и смена режима сохраняют сообщения текущего запуска.
- [x] Формат проверен на реально поддерживаемых ошибках. Полноценные переменные и собственные функции не добавляются ради этой задачи; связанные ошибки и стек вызовов дополняются по мере реализации этих возможностей.
- [x] Ошибки доставки остаются игровыми сообщениями о нарушенных требованиях и не переводятся этой задачей в исключения Python.

## Проверка в Godot

Запустить игровую сцену с редактором. Ввести программы с несколькими поддерживаемыми ошибками, проверить английские сообщения, тип, номер строки, исходный текст и оформление диагностики. Убедиться, что прежние учебные подсказки и внутренние пути GDScript не появляются. Исправить код: сообщение сохраняется до нового запуска, затем очищается. Проверки режима «Шаг» и переключения выполняются после появления соответствующих возможностей.

## Согласовать перед реализацией

Соответствие поддерживаемых ошибок типам и текстам сообщений, отображаемое имя программы игрока и обозначение места ошибки. Конкретная архитектура требует отдельного согласования. Привычный формат Python и английский язык сообщений уже согласованы; привязка к определённой версии Python не нужна.
