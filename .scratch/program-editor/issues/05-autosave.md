# 05: Автоматическое сохранение программы

## Что сделать

Текст программы сохраняется автоматически.

## Зависит от

sorter-bot-concept/01 — Минимальный интерпретатор: первая программа

## Критерии приёмки

- [ ] Текст программы сохраняется автоматически.
- [ ] После обычного закрытия и открытия игры восстанавливается последний изменённый текст.
- [ ] Сохранение игрового мира этой задачей не определяется.

## Проверка в Godot

Запустить игровую сцену с редактором. Изменить текст без ручного сохранения, закрыть игру обычным способом, открыть снова и сравнить текст.

## Согласовать перед реализацией

Конкретное техническое решение и окончательное оформление. Создание задачи не разрешает изменение игрового кода.
