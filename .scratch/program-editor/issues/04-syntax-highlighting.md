# 04: Подсветка синтаксиса

## Что сделать

Редактор выделяет поддерживаемые элементы внутриигрового языка.

## Зависит от

sorter-bot-concept/01 — Минимальный интерпретатор: первая программа

## Критерии приёмки

- [ ] Редактор выделяет поддерживаемые элементы внутриигрового языка.
- [ ] Подсветка охватывает реализованные конструкции, в том числе доступные возможности задач 09–14 основного плана.
- [ ] Пример из задачи 09 проверяет подсветку присваивания `=`, имён переменных, строк и вызова `get_box_color()`.
- [ ] Пример из задачи 10 проверяет подсветку `if`, `else` и сравнения `==`.
- [ ] Пример из задачи 11 проверяет подсветку `while`, `True`, `False` и `pass`.
- [ ] Пример из задачи 12 проверяет подсветку `def`, имени определяемой функции и её вызовов.
- [ ] Возможности стандартного Python автоматически не подразумеваются.

## Проверка в Godot

Запустить игровую сцену с редактором. Ввести примеры поддерживаемых конструкций и проверить подсветку при изменении текста.

## Согласовать перед реализацией

Конкретное техническое решение и окончательное оформление. Создание задачи не разрешает изменение игрового кода.
