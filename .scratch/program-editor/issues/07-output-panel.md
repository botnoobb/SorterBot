# 07: Окно вывода программы под боковым редактором

## Что сделать

Игрок выводит сообщения своим кодом и читает их в автоматически раскрывающейся панели под боковым редактором. В этой же панели показываются ошибки языка и доставки при реализации связанных задач.

## Зависит от

sorter-bot-concept/01 — Минимальный интерпретатор: первая программа.

## Критерии приёмки

- [x] Реализован путь от согласованной команды вывода внутриигрового языка до сообщения в панели.
- [x] Панель расположена снизу под боковым редактором и занимает часть его области, ориентируясь на расположение в референсе.
- [x] Пока сообщений нет, панель скрыта; первый вывод или ошибка автоматически раскрывает её.
- [x] Сообщения отображаются в порядке выполнения; длинный вывод можно прокручивать.
- [x] Новый запуск очищает прежние сообщения. Если новых сообщений нет, панель скрыта; первый вывод или ошибка нового запуска раскрывает её.
- [x] Остановка и завершение сохраняют сообщения видимыми для разбора результата.
- [x] Редактирование сохраняет вывод, в том числе когда первая правка останавливает выполнение.
- [x] «Шаг» из паузы и автоматическое продолжение сохраняют сообщения текущего запуска; переключение режимов через паузу также не очищает вывод.
- [x] «Шаг» из редактирования начинает новый запуск с первой строки и очищает предыдущие сообщения, как автоматический запуск.
- [x] Запрос паузы или полной остановки сохраняет вывод, включая сообщения завершающейся текущей инструкции.
- [ ] Окно вывода остаётся под редактором при размещении справа или слева; смена стороны сохраняет сообщения. Совместная проверка выполняется после появления обеих возможностей.
- [x] По уточнению пользователя от 2026-11-02 существующие ошибки языка показываются в панели вывода. Расширенная диагностика и переход к строке остаются в sorter-bot-concept/02, ошибки доставки — в sorter-bot-concept/05.

## Проверка в Godot

Запустить игровую сцену с редактором. Выполнить согласованную команду вывода несколько раз: проверить раскрытие панели, порядок сообщений и прокрутку. Запустить программу заново без вывода: прежние сообщения очищены, панель скрыта. Проверить сохранение сообщений после завершения, остановки и редактирования.

После появления связанных возможностей проверить ошибки языка и доставки, расположение редактора с обеих сторон, несколько нажатий «Шаг» из паузы и переключение режимов: сообщения текущего запуска сохраняются. Затем остановить программу и нажать «Шаг» из редактирования: начинается новый запуск, прежний вывод очищается.

## Согласовать перед реализацией

Название команды вывода, допустимые аргументы и представление значений. Наличие функции print стандартного Python не предполагается. Окончательное оформление и техническое решение согласуются отдельно; референс задаёт прежде всего расположение.
