# Документация домена

Проект использует единый контекст (single-context).

## Перед изучением кода

- Прочитать `GLOSSARY.md` в корне проекта, если он существует.
- Прочитать документы из `docs/adr/`, относящиеся к текущей задаче.

Если этих документов нет, продолжать работу без уведомлений
об их отсутствии и без предложения создать их заранее.
Термины и архитектурные решения документировать по мере
согласования с пользователем.

## Расположение

- `GLOSSARY.md` — общий словарь терминов проекта.
- `docs/adr/` — записи об архитектурных решениях.

## Терминология

В задачах, спецификациях и предложениях использовать термины
из словаря. Не заменять их синонимами, которые словарь исключает.
Если нужного понятия нет, проверить его по коду и документации;
не придумывать семантику самостоятельно.

## Противоречия решениям

Если предложение противоречит существующей ADR, явно указать
документ и суть противоречия. Не переопределять решение молча.
