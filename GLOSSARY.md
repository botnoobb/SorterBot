# Sorter Bot

Словарь согласованных понятий сортировочного комплекса. Описывает язык игрового мира.

## Термины

**Заказ**:
Требование внутри игрового мира, которое определяет нужную производству работу и объясняет игроку, зачем менять программу.
_Не использовать как синоним_: задача. Слово «задача» используется в обычном смысле для того, что предстоит решить игроку, и не является отдельным термином игры.

**Груз / коробка**:
Предмет, который робот доставляет в зону согласно требованиям сортировки. «Груз» и «коробка» — равнозначные названия.

**Вид / свойство груза**:
Характеристика груза, по которой задаются требования к его сортировке. «Вид» и «свойство» используются как синонимы.

**Инструкция программы**:
Элемент программы, определяющий действие или управление ходом выполнения. Не равнозначна строке текста: порядок выполнения инструкций определяется логикой программы, включая циклы и ветвления.
_Не использовать как синоним_: строка, команда.

**Пауза выполнения**:
Временное приостановление текущего запуска после завершения текущей инструкции с сохранением состояния программы. Продолжение возобновляет этот же запуск со следующей инструкции по ходу выполнения, в том числе внутри цикла, без повторения только что завершённой инструкции.
_Не использовать как синоним_: остановка выполнения.

**Остановка выполнения**:
Прекращение текущего запуска программы без возможности продолжить его с места остановки: следующий запуск выполняет программу с начала. Расположение объектов сохраняется.
_Не использовать как синоним_: пауза выполнения.
